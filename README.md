# Text Polisher · Редактор ответов SillyTavern

Расширение отправляет **готовый ответ ИИ** отдельной модели-редактору и заменяет сообщение её результатом. Русский интерфейс, предпросмотр, автозамена, откат и правила Тилла уже включены в пакет. Сборка и npm-зависимости для установки не нужны.

## Что умеет

- Автоматическая редактура после завершения генерации, включая новые свайпы и продолжения. Старые свайпы при просмотре повторно не отправляются.
- Галочка **«Предпросмотр перед заменой»**: исходник и результат рядом, результат можно поправить вручную. Если снять галочку — автоматическая замена.
- Ручная редактура последнего ответа и кнопки **✎ / ↶** в дополнительных действиях каждого сообщения персонажа.
- Исходник сохраняется в данных соответствующего свайпа и доступен после перезапуска Таверны. Повторная редактура сохраняет самый первый исходник. После ручной правки откат откажется перезаписывать текст.
- Отдельные URL, ключ, модель и параметры редактора. Основное API-подключение SillyTavern не меняется.
- Стриминг редактора включён по умолчанию: промежуточный текст виден в панели, таймаут сбрасывается при поступлении данных. Ответ заменяется только после завершения.
- Явный запрет менять решения, намерения и выбранные действия персонажа. Проверка поз и движений по пяти предыдущим сообщениям.
- Проверка избыточных эпитетов и независимые галочки отправки карточки персонажа и персоны пользователя.
- Сохранение выразительности, ритма, силы реплик и конкретных деталей: очистка не должна превращаться в пересказ или систематическое сокращение.
- Каталог моделей, таймаут, отмена, защита от устаревшего результата после смены чата, свайпа, удаления или ручной правки сообщения.
- При ошибке API, пустом ответе, отказе или признаке обрезанного ответа исходник сохраняется.

## Установка через GitHub

1. В SillyTavern открой **Extensions / Расширения → Install extension / Установить расширение**.
2. Вставь **https://github.com/gowwwther/st-text-polisher**, установи и перезагрузи страницу.
3. Открой настройки **Text Polisher**, выбери провайдера, введи API-ключ и выбери модель.
4. Начни с ручной редактуры и предпросмотра; затем включи автоматическую обработку по желанию.

Друзьям передай эту же ссылку: **https://github.com/gowwwther/st-text-polisher**. Каждый использует свой ключ. Для обновления — Manage extensions → Update.

### Обновление 1.1.0

Добавлены стриминг и таймаут паузы между данными, просмотр промежуточного текста, проверка корректного завершения потока и сохранение исходника при обрыве. Усилены требования сохранять выразительность и смысловую силу реплик. Все три исходных файла правил сохранены без изменений. После обновления перезагрузи страницу и введи ключ снова.

Можно установить вручную: скопируй папку `st-text-polisher` в `SillyTavern/data/<user-handle>/extensions/`. Для установки всем пользователям — в `SillyTavern/public/scripts/extensions/third-party/`. Не устанавливай обе копии одновременно.

## Подключение

Открой **Расширения → Text Polisher · Редактор ответов → Подключение API**.

| Провайдер | Base URL |
| --- | --- |
| rout.my | `https://api.rout.my/v1` |
| LinkAPI | `https://linkapi.ai/v1` |
| Другой OpenAI-совместимый API | Его адрес до `/chat/completions`, например `https://example.com/v1` |

Кнопки `rout.my` и `LinkAPI` подставляют URL и очищают ключ/модель, чтобы данные предыдущего провайдера случайно не ушли новому.

1. Выбери провайдера или введи Base URL.
2. Введи свой API-ключ редактора.
3. Нажми **«Загрузить модели / проверить ключ»**.
4. Выбери точный ID модели в поле модели либо впиши его вручную. Нужна модель, поддерживающая **Chat Completions**, текстовый ответ и системные инструкции. Каталоги могут содержать также модели для других задач.
5. Оставь предпросмотр включённым и нажми **«Редактировать последний ответ»**.
6. Когда результат устраивает, включи **«Автоматически редактировать новые ответы ИИ»**. Для мгновенной замены сними галочку предпросмотра.

**Ключ хранится только в памяти открытой страницы**, не записывается в настройки, localStorage или репозиторий. После перезагрузки страницы его нужно ввести снова. Запрос передаётся серверу SillyTavern, который обращается к провайдеру; отдельный серверный плагин и браузерный CORS провайдера не нужны.

Расширение использует серверный маршрут SillyTavern `/api/backends/chat-completions/generate` с `custom` source и собственным заголовком Authorization для конкретного запроса. Постоянный Custom API-ключ основного подключения не изменяется. Как у любого клиентского расширения, ключ в открытой странице доступен исполняющемуся в ней коду; устанавливай доверенные расширения.

## Правила и контекст

Три блока включаются независимо:

- **Основной BAN LIST** — полный текст из сообщения Тилла: слова, клише, negative reframing, искусственные эмоции, избыточная инвентаризация, принцип замены, все пояснения и исключения. Обычное фактическое отрицание разрешено.
- **Расширенные запреты B1–B10 / S1–S10** — первый приложенный файл целиком, без изменений, включая техническую преамбулу. Строже основного списка: явные перечисленные формы имеют приоритет над более мягкими исключениями. Обёртка редактора отдельно уточняет область применения: готовый ответ, сохранение решений персонажа, без добора длины и без восемнадцати отдельных платных API-запросов. Сами исходные пояснения не удалены.
- **Инициатива персонажа / убрать передачу хода** — второй приложенный файл. Редактору отдельно запрещено сочинять новые события и эскалацию для выполнения этого правила; правка использует существующие действия/намерения, иначе убирает лишнюю передачу хода.

В **«Дополнительных пожеланиях»** можно добавить свои требования. Кнопка **«Открыть активные правила»** показывает фактически отправляемую системную инструкцию. Для правки встроенных правил редактируй `rules/*.txt` и перезагружай страницу.

По умолчанию передаются **пять предыдущих сообщений** и основные поля карточки говорящего персонажа: описание, личность, сценарий, примеры диалогов. Для групп карточка выбирается по `original_avatar`. Активная персона пользователя — имя и описание из SillyTavern — отправляется по отдельной галочке. Эти две галочки независимы. Количество сообщений можно изменить; `0` отключает историю. Lorebook, скрытые рассуждения, полный пресет и прочие расширения контекста не включаются.

Предыдущие сообщения помогают сверить позы, расположение рук, одежду, предметы и последовательность движений. **Редактируется только текущий ответ**, история не переписывается. Модель не должна менять решения персонажа и добавлять промежуточные действия ради исправления логики. Если контекст недостаточен, она должна сохранять неопределённость.

Галочка **«Проверять эпитеты»** включена по умолчанию: одно точное определение предпочтительнее цепочки «взгляд был тяжёлый, ясный». Два самостоятельных значимых определения допустимы через «и», без постоянного повторения этого приёма. Фактические признаки вроде цвета, материала и травмы не вырезаются механически.

Промпт требует локальной правки: сохранять допустимые выразительные детали, ритм, голос и эмоциональную интенсивность. Удаление лишнего эпитета не должно вести к упрощению всего абзаца. Команда, обещание, угроза или уверенное утверждение сохраняют свою силу: замена «я заставлю» на «я хочу» запрещена. HTML, цвета и структурные маркеры сохраняются; после удаления проверяются связи между предложениями.

Редактор сохраняет неизменённые фрагменты, события, POV, смысл реплик и голос персонажа. Семантические запреты интерпретирует выбранная модель: абсолютной гарантии удаления всех клише и сохранения всех оттенков смысла нет. Начни с предпросмотра. Регулярные выражения не используются как замена смысловой редактуре.

Каждая редактура — один дополнительный оплачиваемый запрос по тарифу твоего провайдера. Длинные правила и карточка увеличивают входные токены. Автоматических повторов после ошибки нет. Загрузка моделей не вызывает текстовую генерацию. Если основной ответ Таверны генерируется потоком, редактура начинается после его завершения.

## Стриминг редактора и таймаут

Галочка **«Стриминг ответа редактора»** находится в подключении API и включена по умолчанию. Редактор запрашивает OpenAI-совместимый SSE-поток. Его промежуточный текст виден в панели **«Поток редактора»**, доступен только для чтения и ещё не считается готовой редактурой. После завершения открывается обычный предпросмотр либо применяется автоматическая замена, в зависимости от галочки предпросмотра.

В стриминге **таймаут ограничивает ожидание первых данных и паузу между последующими порциями**, а не общую длительность генерации. Его сбрасывают также служебные сообщения и отдельные reasoning-данные; сами рассуждения не показываются, не отправляются повторно и не сохраняются в чат. Если модель долго молчит перед первыми данными, увеличь таймаут. Стриминг не устраняет ограничения времени на стороне провайдера или промежуточного сервера.

При обрыве без признака завершения, превышении лимита токенов, ошибке API, отказе модели или отмене частичный текст не применяется. Кнопка **«Отменить запрос»** и смена чата очищают промежуточный текст. Если API игнорирует стриминг и возвращает JSON, расширение обрабатывает обычный полный ответ. Если API не поддерживает стриминг, сними галочку; автоматического повторного платного запроса нет. Без стриминга таймаут ограничивает весь запрос.

## Совместимость и ограничения

Реализация сверена с веткой `release` SillyTavern. Ядро, полные правила и потоковый транспорт проверены 26 автоматическими тестами: UTF-8 и SSE на границах пакетов, reasoning/keepalive, таймаут паузы, отмена, обрыв, ошибки и JSON-ответ. Отдельно проверены действия интерфейса и события ST в DOM-окружении с имитацией API, включая потоковый предпросмотр, автоматическую замену после завершения и сохранение исходника при обрыве. Реальный оплачиваемый запрос с ключом пользователя, визуальная проверка в браузере и его установленная сборка SillyTavern требуют проверки на его стороне.

Приветствия, пользовательские, системные и пустые сообщения не редактируются автоматически. Новая генерация отменяет выполняющийся запрос редактора. Для групп результаты ждут окончания генерации; предпросмотры показываются последовательно. Если начать новую генерацию с открытым предпросмотром, он закроется.

Расширение обновляет `mes`, активный `swipes` и `swipe_info`, перерисовывает сообщение и сохраняет чат. Кэш `display_text`/счётчик токенов сбрасывается при правке. Скрытые reasoning-поля остаются исходными и могут расходиться с отредактированным текстом. Правки через API не запускают повторно `MESSAGE_RECEIVED` и не зацикливаются.

Переводчики, TTS и другие обработчики ответа могут успеть обработать исходник до редактора. Автоперевод в `display_text` очищается при замене. Для интеграций есть событие `text_polisher:message_updated(messageId)`. Если используются расширения, одновременно переписывающие ответы, проверь их совместную работу на копии чата.

## Если что-то не работает

- `401/403`: проверь ключ и права аккаунта; после перезагрузки страницы введи ключ снова.
- `404`: проверь URL и точный ID модели. Для двух встроенных провайдеров используй адреса из таблицы.
- Модель не найдена: возьми точный ID из каталога аккаунта. Наличие в каталоге ещё не гарантирует Chat Completions.
- Ответ обрезан: увеличь лимит выходных токенов; выбери модель, позволяющую такой лимит.
- Таймаут: включи стриминг; если модель долго молчит перед первыми данными, увеличь таймаут или выбери более быструю модель. Исходник останется.
- API не поддерживает стриминг: сними его галочку и запусти редактуру вручную. Повторный запрос оплачивается отдельно.
- Не видны кнопки: проверь дополнительные действия сообщения или используй кнопки в панели расширения.
- Ошибка серверного API: обнови SillyTavern и проверь его журнал.
